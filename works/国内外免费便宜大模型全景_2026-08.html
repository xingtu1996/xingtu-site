一、先澄清：GPT-5.6「Luna」是不是免费？

很多人把 luwa 当成某个新模型，其实是 GPT-5.6 Luna——OpenAI 2026-07 发布的 GPT-5.6 系列分 Sol / Terra / Luna 三档，Luna 是最便宜最快的轻量档。结论：免费，但有边界

✅ 免费范围 自 2026-08-06 起，Luna 成为 ChatGPT Free 和 Go 档的默认模型，文字对话取消次数限制（unlimited text chats），并首次给免费档开放「Think」深度推理开关。Plus / Pro 用的是更强的 Sol 档。
⚠️ 不是全免费 「无限」仅限纯文字对话；文件上传、图片生成、重度 agent 功能仍有限额。Luna 推理深度弱于 Sol，做严肃长代码仍然要付费档或别的方案。
💸 API 省钱陷阱 Luna 的 API 价 7-30 直降 80%，现为 $0.20 / $1.20（输入/输出 每百万 token），是 GPT-5.6 系最便宜入口。但裸调 gpt-5.6 会被默认路由到最贵的 Sol，成本敏感必须显式指定 gpt-5.6-luna。

3.2 用量监控：避免意外扣费（重点）

① 开「用完即停」

阿里云百炼「免费额度用完即停」、火山方舟「安心体验」用完自动暂停——务必开启，否则循环调用会意外欠费。

② 别开后付费

默认关闭后付费 / 自动续费。免费额度耗尽后手动决定要不要开按量，别让系统自动扣。

③ 设预算告警

云控制台都有「余额告警 / 预算上限」，设一个低阈值（如 ¥10），触发就停手。

④ 不拿免费额度跑批量

豆包等明确：免费额度不抵 Batch 批量推理 / 插件调用 / 知识库调用。别拿它跑离线打标，那部分直接进账单。

⑤ 有效期当心

90 天 / 1 年过期作废，别把免费额度写进长期项目预算；用完即止，验证完迁便宜按量。

⑥ Key 最小权限

用 IAM 子账号 / 最小权限；API Key 只显示一次，当场存好，别泄露到代码库。

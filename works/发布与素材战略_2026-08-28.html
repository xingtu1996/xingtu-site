行途 · 发布节奏与素材供给战略

核心结论：公众号首发 + 多平台异步分发，是最稳的组合。 控制 1 个主战场（公众号）把「深度 + 互动 + 变现」做厚；其余平台（掘金 / CSDN / GitHub / X）作为异步分发烟囱，按各自流量逻辑错峰发布，降低多平台同步维护成本。内容供给则完全建立在真实工程会话上——从 重构工程仓 等项目的 601 个真实会话里挖「意图 vs 证据」落差，做到可追溯、可复现、可出书。

一、多平台分发节奏（首发 → 分发）

原则：一篇成文，分层复用。公众号首发拿原创与互动，其他平台隔 6–72h 按形态改写，避免「通稿」被限流（PUB-004）。

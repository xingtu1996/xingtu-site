一、域名知识

#知识点关键事实 / 用法标签
1域名是租用非买断标准后缀按年付费；「终身域名」=注册商代续费承诺（商倒即没）；区块链域名(.crypto/.eth)非标准 DNS，做 IP 阵地是死路避坑
2国内注册必须实名国内注册商买的 .com 也要实名（15 天内否则暂停解析），不止 .cn规则
3续费刺客.top/.xyz 首年 9.9 → 续费 60-80；.com 续费 69-89、.cn 35-45 元/年 稳定；买完开自动续费+年限拉满避坑
4隐私保护国内半多余实名后 WHOIS 已脱敏且监管可见；真需隐私保护是海外注册商场景避坑
5撞名先于可用性拼音 xingtu 撞 兴图/星途/星图（字节）→ 拥挤命名空间；品牌 collision 比域名被占更致命风险
6后缀选型国内 SEO 选 .cn（可备案）；开发者向 .dev（Google、强制 HTTPS、~$12-15/年）；极客 .io（~$32-40/年）决策
7实测工具whois 批量查占用；whois 服务器不通用 RDAP（ICANN HTTP 接口）；注册商「建议页」全是溢价 upsell工具
8免费方案Cloudflare Pages `*.pages.dev`（永久免费/可商用/国内最快）；GitHub Pages 仓库必公开；Vercel/Netlify 免费禁商用决策
9Cloudflare Wallet Handle 抢注2026-08-04 发布；cloudflare.pay 抢注 `名.cloudflare.pay`（3-32 字符），先到先得、一账号仅 1 个；身份预留券（非钱包/空投）；未来 AI Agent 收款身份（x402+USDC）资产
10Email Routing 品牌邮箱买自定义域名后 CF 免费转发 `agent@域名` 等品牌邮箱到个人邮箱资产

二、GitHub 知识

#知识点关键事实 / 用法标签
1改名规则旧用户名立即释放可被抢注；仓库 URL 自动重定向；旧主页/gists 永久 404；本地 remote 要手动更新规则
2账号年龄`curl -s https://api.github.com/users/名 | grep created_at`；年龄随账号不随用户名工具
3SSH key公钥挂 Settings→SSH keys；本机走 443+ProxyCommand；`ssh -T ***@***` 验证工具
4gh CLI 授权设备流需 POST github.com（本机直连不通→走代理或 PAT）；`GH_HOST=github.com` 强制个人主机；`--with-token` 存 PAT避坑
5commit 邮箱用 noreply `ID+USERNAME@users.noreply.github.com`；禁止公司邮箱（全局已配 Justin Li）规则
6私有仓库+gitignore 双保险敏感目录永不入库；vault .gitignore 已排除 素材库/运营资产安全
7招聘观感三层Profile README（门面）+ Pinned 代表作（证据）+ resume 仓库（凭证）；空账号年龄救不了观感决策
8同名仓库特殊仅 `用户名/用户名` 是 Profile README 特殊仓库；`docs` 等普通仓库无特殊规则

三、Cloudflare / 部署知识

#知识点关键事实 / 用法标签
1Pages 原理每次部署=不可变快照（类 git commit）；专属 URL 永久可访问；可 Rollback 秒恢复原理
2无服务器文件存边缘存储、全球 300+ 节点分发；无进程→不会挂、免维护原理
3免费商业模式免费层=获客漏斗；边际成本≈0；金主是企业 CDN/安全合同；个人站事实永久免费原理
4token 权限部署需 Account:Cloudflare Pages:Edit + Account:Account Settings:Read（wrangler 要列账号）避坑
5wrangler 4 坑无 --yes 标志；首次部署新项目非交互报错→先 API 建项目再 deploy避坑
6自定义域名Custom domains 绑真域名（CNAME→pages.dev 或 CF 托管自动）；CF 免费管证书；免备案决策
7国内 SEO免备案≠国内快；搜一搜 SEO 需 .cn + ICP 备案（7-20 天，需国内轻量服务器 ~60-100 元/年）避坑

四、网络与环境知识

#知识点关键事实 / 用法标签
1本机连通性直连 github.com 000；走 127.0.0.1:7897 代理 200；api.github.com / api.cloudflare.com 直连通；SSH 走 443+代理通白盒
2先测再猜`curl -sI 目标 -o /dev/null -w "%{http_code}"`；000=不通，200=通工具
3agent-browser 沙箱限制每命令结束回收后台进程；跨命令自动化不可行→登录/表单由本人操作，AI 做开页+验证避坑
4代理配置浏览器/CLI 需显式 `--proxy http://127.0.0.1:7897` 或 `HTTPS_PROXY=`；gh 用 GH_HOST 切主机工具

六、安全知识

#知识点关键事实 / 用法标签
1凭证不入聊天密码/PAT/API Token 贴聊天=暴露；操作完必须 revoke/改密红线
2git 公司邮箱禁令一律 noreply；公司仓库本地覆盖须 boss 同意红线
32FA + 备用邮箱账号单点恢复=单点风险；加独立备用邮箱 + TOTP + recovery codes红线
4凭据不存明文台账只记位置不存值（SAF-003/011）规则
5登录不代操作AI 不代登录/改绑定/申诉；只做模板与提醒规则

主题论证要点（来源标注）结论
WorkBuddy 信任① 模型层：腾讯云与模型厂商签协议——数据仅实时推理、不留存、不训练（官方公众号 2026-06）；② 产品层：习惯数据采集可关闭；自定义模型 API Key 仅存本地设备（腾讯隐私保护指引）；③ 平台层：文件处理本地化（Excel/PDF 原始数据不上传）、传输全加密、信通院 Claw 可信评估、操作可审计（腾讯云开发者手册）可信度较高，但「操作记录/日志会记录」→ 敏感会话内容仍建议谨慎、不贴明文凭证

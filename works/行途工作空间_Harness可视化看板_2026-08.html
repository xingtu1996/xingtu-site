安全武器库

从 CC harness 迁来并改造，工作区本地自带，不依赖 CC 地盘
safe-delete.sh ✓ 冒烟通过
mv 进工作区本地 .trash，带禁区越界防护，可 --restore 还原、--list 查看、--clean N 清 N 天前。直接对抗「不要 rm -rf」。
backup-before-op.sh ✓ 冒烟通过
操作前打包带时间戳 tar.gz 快照到 .backups，落地「做好备份」诉求。用法：bash backup-before-op.sh '说明' <路径>
env-check.sh ✓ 17 PASS
为 xingtu 重写的环境自检：磁盘/工具链/锚点/六层/安全脚本就位与否。进空间先跑一遍。
gate.sh ✓ 自检 PASS
海事工程仓 spec Hard Gate 参考副本，发布/交付前结构校验（specs 缺失仅为 WARN，符合 xingtu 现状）。
路径已中文化改造：原 CC 版回收站写死 ~/.claude/trash，现改为工作区本地 .trash/.backups，让 xingtu 自带安全机制、跨平台可跑。配套 README.md 说明用法与跨平台注意点。

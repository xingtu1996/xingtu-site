二、公众号连接器准备步骤（重点）

1取 AppID / AppSecret
登录 mp.weixin.qq.com → 左侧「设置与开发 / 基本配置」→ 拿到 AppID(开发者ID) 与 AppSecret(开发者密码)。 若 AppSecret 遗忘需重置（会让你扫码确认）。
2确认接口权限
「设置与开发 / 接口权限」里确认 用户管理（获取用户基本信息、获取用户列表）已获得。订阅号/服务号通常默认有；未认证订阅号可能受限。
3落地密钥（安全）
复制 tools/wechat_audience_config.example.json → 改名 wechat_audience_config.json → 填入真实值； 并把该文件名加入 .gitignore（密钥绝不入库）。也可改用环境变量 WX_APPID / WX_APPSECRET。
4跑取数连接器
python3 tools/wechat_audience_puller.py --config wechat_audience_config.json --out 受众实测画像.html
脚本自动拉全部粉丝 openid → 批量 user/info → 聚合性别/省份/语言/关注时间 → 输出单文件看板。
5校验再下结论
把实测画像和上一版「推断画像」对照：性别比、地域集中度、关注时间是否与"程序员/技术经理"假设吻合，再修正 IP 战略。

四、无 API 平台的"手动连接器"方案

对这些平台，我这边没法程序化拉数，但可以承接你导出的数据：

  • 统一收口目录：把各平台后台导出的 CSV / 截图放到 素材库/后台数据/（待建，本地私有），文件名带平台+日期。

  • 目标：把"公众号实测 + 多平台手动导出"拼成一个统一粉丝画像看板，补漏公众号覆盖不到的维度。

5排序模型：从三分公式升级到「五维汲取分」

现有公式已埋好骨架（0.5×时效 + 0.3×长尾 + 0.2×价值），缺「阶梯缺口」这一维
现有：publish_priority = 0.5×时效紧迫 + 0.3×长尾SEO + 0.2×工具价值（0–100）
问题：入门概念卡价值分不高（如「理念-复利进化」34.6 分），永远排在 60.7 分的 agent 卡后面 —— 「缺什么发什么」没有被编码进公式。
建议升级：汲取分 = 时效紧迫 30% + 阶梯缺口 25% + 长尾SEO 20% + 价值密度 15% + 破圈力 10%
阶梯缺口 = 当前 L0 缺口最大 → 概念/理念卡加权（当前阶段该权重自动顶到 25%）；破圈力 = 可发知乎/小红书泛流量的加分。等 L0 补足后，权重向 L2 倾斜 —— 权重跟着阶梯缺口走，而不是永远静态。

阶梯缺口25%（新增）按当前内容阶梯缺口加权现在缺口 = L0 概念层 → 理念卡/入门卡自动上浮

价值密度15%value_score（GOLDEN/KEY/FOCUS/INSIGHT）黄金级 G1–G6 优先成稿
破圈力10%（新增）可否发知乎/小红书泛流量清单体、截图教程、争议观点 → 加分
落地动作：① 给快消类素材重标 freshness_days（7–30 天）→ ② 卡片补「ladder」字段（L0–L3）→ ③ 公式加阶梯缺口 + 破圈力两维 → ④ 每日飞轮按新分推卡。

8WorkBuddy 模型选型：Auto 模式深度拆解

你现在是 Auto 模式 —— 直接结论：本次这类「深度分析 + 规划」任务，Auto 是错配，应锁 deepseek-v4-pro（依据 tools/model_assignment.json）

① Auto 模式的真相：它不是「最好」，是「最省心」

Auto 的代价：模型由系统按任务路由，对内容创作是「质量盲盒」——文风漂移（这篇像 Pro、下篇像 Flash）、精细指令丢失（「分层结论+待议」「禁 AI 味」这类规则不会被严格执行）、跨篇一致性无法保证。素材库的既有规则（模型分配 json 的 auto_mode 条款）写得很明确：「错配代价低的任务用 Auto，错配代价高的任务锁死 V4-Pro。默认锁 V4-Pro 而非 Auto（防懒切换）」。

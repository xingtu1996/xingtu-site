行途 / XingTu · 域名与建站 MVP 方案

面向「实战派技术深耕者」个人 IP 的双轨落地方案（MVP 先跑 + 长远可升）

2026-08 已核实价格/政策 单文件离线

先澄清你转发的指南：大方向正确，3 处修正 —— ① 国内注册商买的 .com 也必须实名（15 天内，否则 ServerHold）；② 国内注册 WHOIS 已脱敏+监管可见，隐私保护"半多余"，阿里云/腾讯云对 .com/.cn 多免费赠送，真需隐私保护的是海外注册商；③ 捆绑项不止 DNS/SSL，还有企业邮箱/建站模板/SSL 试用包，结算页只留"域名+DNS 管理"。

一、双轨战略（长远 + MVP）

🟢 MVP 轨道（现在就做）

目的：最低成本把品牌占位 + 一个能访问的作品集/博客跑起来。

  • 买 xingtu.cn（国内注册商，~20–45 元/首年，便宜长期持）
  • 免费托管 Cloudflare Pages（无限带宽、国内境外中最快、可商用、支持私有仓库）
  • 绑定自定义域名 + 自动 HTTPS，免 ICP 备案
  • 总成本：域名 ~20–45 元/年 + 托管 0 元

🔵 长远轨道（IP 做起来后）

目的：国内速度 + 微信搜一搜/百度 SEO 友好，承接变现。

  • 买国内轻量服务器（腾讯云 99–199 元/年）
  • 用已持有的 xingtu.cn 做 ICP 备案（7–20 天，国内注册商可直接办）
  • 解析切到国内，搜一搜长尾流量起飞
  • 品牌保护：补 xingtu.com（若未被溢价）、xingtu.dev/.ai 作技术副域名

四、免费方案的"呕心"坑（必看）

  1. 国内访问慢 / 无备案 → 微信搜一搜、百度收录和排名吃亏，视频号/公众号联动弱。要做国内阵地迟早要备案（长远轨道已规划）。
  2. Vercel / Netlify 免费禁商用 → 你做知识星球 / 广告植入属于商业化，违规会被封号。真要变现得升 Pro。
  3. GitHub Pages 免费仓库必公开 → 草稿、配置、未发布内容全暴露；介意就用 Cloudflare（支持私有仓库）。
  4. "免费首年"域名是引流 → .top/.xyz 首年 9.9，续费飙到 60–80，别被首年价骗。
  5. 免费 DNS/托管超限或政策变 → 迁移有成本，所以域名锚点（xingtu.cn）自己握在手里最稳。

五、操作清单（MVP 版，照做即可）

A. 买域名（以腾讯云为例，阿里云同理）

  1. 域名控制台搜 xingtu → 看 .cn 是否可注册、价格。
  2. 建「域名信息模板」（个人：身份证 + 人脸识别），等过审（1–3 工作日）。
  3. 下单 xingtu.cn，年限选 1 年，开启自动续费（防遗忘被回收）。
  4. 结算页点开「价格明细」，只留"域名 + DNS 管理"；取消隐私保护（国内多余）/ 企业邮箱 / 建站模板 / SSL 试用包。
  5. 支付（约 20–45 元）。
  6. 等 .cn 命名审核 1–3 工作日 → 状态变「正常」即可解析。

B. 免费托管（Cloudflare Pages）

  1. 注册 Cloudflare（免费账号）。
  2. Workers & Pages → Create → Pages → 连 GitHub 仓库（或上传 HTML）。
  3. 部署（可用你现有的 HTML 作品集 / 博客源）。
  4. 拿到平台给的 CNAME 地址。
  5. 回腾讯云 DNS 解析：加 CNAME（主机 www → Cloudflare 地址；可选 @ 同指）。
  6. 开 Cloudflare 代理（橙色云图标）+ 自动 SSL → 几分钟生效，完成。

总成本：域名 ~20–45 元/年 + 托管 0 元。将来要国内速度/SEO，同一 xingtu.cn 直接做 ICP 备案切国内，平滑过渡。

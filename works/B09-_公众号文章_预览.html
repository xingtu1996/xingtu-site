改 1 个配置，账单瘦了

发布日期：2026-08-28 · 配置全部来自 Claude Code 官方文档 · 配图自制

用 AI 编程工具久了，账单才是真正的"沉默成本"。上周翻 token 账单，我盯着输出侧的数字愣了一下——比预想的厚了不少。翻了一圈官方文档才发现：很多东西其实都写着，只是没人翻。我把 Claude Code 的回复配置从默认改成 Concise，又调了一个压缩阈值，实测下来，输出侧肉眼可见地瘦了。这篇一次性讲清楚。

先给一个判断：AI 编程烧钱，绝大多数时候不是"用太多"，是"配置没对"。工具的成本有一半藏在配置里，而配置这层，恰恰是大多数人从不翻开的那页说明书。

一、核心发现：outputStyle（输出样式）

官方定义：输出样式改变的是 Claude 的「响应方式」，不是它「知道什么」。官方内置 5 档风格：

档位官方定位适合谁
Default默认，高效完成软件工程任务通用
Proactive立即执行、合理假设熟手赶进度
Concise先给结果、跳过铺垫、默认简短省钱/要效率
Explanatory边做边讲，加教育性 Insights学习期
Learning协作式边学边做，留 TODO刻意练习
📊 插入配图：outputStyle 5 档风格（Concise 高亮）图2_五档风格.png
两种调整方式：① 命令 /config → Output style ② 直接编辑 settings.json 加 "outputStyle": "Concise"。旧 /output-style 命令已废弃。

三、deepseek[1m] 用户必看

模型 ID 含 [1m] 时，MAX_CONTEXT_TOKENS 不独立生效，必须设 DISABLE_1M_CONTEXT=1。

四、一句话抄作业

settings.json 加 Concise → 压缩阈值 800000 → deepseek[1m] 加 DISABLE_1M_CONTEXT=1 → 先试跑。
